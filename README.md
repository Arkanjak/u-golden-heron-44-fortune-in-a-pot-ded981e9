A tiny TypeScript program that writes one kind, funny fortune for a houseplant — a single line of 115 characters, written for the plant on the windowsill — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

The program embeds the fortune, checks it against the gate (1–120 characters, one line, not only white space), and writes the same bytes from any working directory. No network, no external files.
